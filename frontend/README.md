# Spend Wise React frontend

This React + Vite frontend preserves the existing Spend Wise HTML markup, CSS, images, and DOM-driven interactions without changing the visible design.

## Run
1. Start the Express backend from `../backend` on port 5000.
2. In this folder run `npm install`, then `npm run dev`.
3. Open `http://127.0.0.1:5173`.

Vite proxies `/api` calls to `http://127.0.0.1:5000`.
